# AP2-Programacao-e-Algoritimo

Abra o código com o idle, VScode ou qualquer outro meio que possa inicializar em interagir com 1 arquivo.py. 

Você deverá fazer uma listagem de 5 produtos, cada um com seu nome e preço próprios.

Ao testar sempre que for inserir um valor digite o valor dele seguido pelos decimais separados por um ponto "."
  
***
      Ex: 
      - 45.23
      - 9.1
      - 86.234

Enquanto estiver testando-o procure:
- Evitar utilizar Números negativos
- Evitar o uso de Vírgula
- Evite o uso de "0" como o prímeiro número do valor
